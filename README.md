# Ötüken — Bozkurt'un Destanı

Tarayıcıda oyna: **https://taha123123224.github.io/otuken/**

Bu depo oyunun yayındaki sürümüdür. Buraya gönderilen her değişiklik:
- web sürümünde yaklaşık bir dakika içinde görünür,
- bilgisayardaki oyunlarda (Otuken.exe) "Yeni sürüm hazır · Şimdi güncelle" olarak çıkar; yalnızca değişen dosyalar indirilir.

| Dosya | Ne işe yarar |
|---|---|
| `index.html` | Oyunun kodu |
| `veri/` | Modeller, animasyonlar, ses efektleri |
| `ses/` | Müzikler |
| `surum.json` | Yayındaki sürüm ve dosya özetleri (güncelleyici bunu okur) |
| `panel/` | Yönetim paneli |

Müzik, model ve ses lisansları: `LISANSLAR.txt`.
